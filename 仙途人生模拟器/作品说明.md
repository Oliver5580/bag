# 浮生仙途 · 人生模拟器（修仙篇）— 作品说明

> 项目代号：仙途人生模拟器 ｜ 类型：纯前端网页游戏 ｜ 形态：单机、零依赖、零构建
> 文件清单：`index.html`（145 行）＋ `style.css`（622 行）＋ `game.js`（2,772 行）＋ `assets/` 立绘资源 ＋ `CG真人风提示词包.md` ＋ `serve.ps1`

---

## 一、作品背景

《浮生仙途》是一款以东方修仙世界观为舞台的**文字人生模拟游戏**。玩家从出生开始扮演一位凡人（或仙门子弟），每回合一年，通过选择生活行为与面对随机事件，在善恶、机缘、情缘与寿元的交织中走完一生——凡人、炼气、筑基、金丹、元婴、化神、渡劫、大乘，直至飞升；气血归零、寿元耗尽或负债累累，皆是一世之终。

创作动因有三：

1. **品类空白**：「人生重开模拟器」证明了文字人生模拟的爆发力，但市面作品普遍缺少"成长经营感"（每年做什么由玩家决定）与"修仙叙事"的深度融合。本作把二者合并：**行为驱动养成 + 随机事件改命 + 里程碑抉择塑形**。
2. **修仙母题的数字化**：灵根资质、境界突破延寿、道侣双修、心魔走火、善恶因果……这些修仙小说的核心意象被逐一转译为可玩的数值系统。
3. **AI 原生创作实验**：本作是一次"单人 + AI 协作"的完整游戏工程实践——美术立绘由 AI 生成、CG 场景提供 AI 图/视频热替换接口、背景音乐为 Web Audio 程序化原创作曲（参考田园序曲风格特征，自写旋律规避版权），全程无第三方素材依赖。

## 二、核心功能

### 1. 开局养成系统
- **出身**（修仙世家 / 凡人富户 / 山村贫户 / 随机天命）、**天赋**（天生道体 / 先天体弱 / 八面玲珑 / 剑心通明 / 随机），越强越贵，占用资质点。
- **流派一键分配**：剑修、书修、情修、均衡、天命随机五套权重模板，剩余点数按流派自动分配到精力 / 悟性 / 魅力 / 灵性（单项有上限）。
- 随机姓名生成（20 姓 × 28 字），随机预览"此世情缘"。

### 2. 回合制人生引擎
- 每回合 = 一年。七种**生活行为**：修炼 / 学习 / 打工 / 运动 / 社交 / 休息 / 挥霍，各自收益与代价不同，并受天赋、灵根、境界、家境、双修等十余个系数调制。
- **三维枯竭机制**：气血 / 道心 / 精力低于阈值后行动减效并触发负面事件（如"走火入魔"），强制玩家经营节奏，杜绝无脑单行为刷到底。

### 3. 事件与抉择叙事
- **随机事件库**：按幼年 / 少年 / 青年 / 中年 / 老年 / 灾难 / 情缘 / 旧识重逢 / 升迁 / 三维枯竭分章，概率受出身、天赋、善恶值调制。
- **13 个抉择里程碑**：6 岁灵根觉醒大典（锋芒毕露 vs 藏拙守愚）、12 岁后山探宝、15 岁情窦初开、18 岁命运十字路口（仙门 / 科举 / 从商三途定职业线）、25 岁退婚风波、30/36/45/55/60 岁人生节点……选择即命运。
- 全部事件文案原创，配套数值结算与"生平大事记"标记。

### 4. 修仙成长体系
- **四等灵根**（天 / 真 / 凡 / 伪，按权重投掷）决定修炼倍率与突破概率；**八大境界**逐级抬升修为需求与寿元上限（凡人 80 载 → 大乘 1000 载），修为 8000 可**飞升**。
- 职业线：杂役弟子 → 外门 → 内门 → 真传 → 长老，或书院学子 → 学士 / 账房 / 掌柜 / 县令等凡俗路线，薪水表驱动经济。

### 5. 情缘与家庭系统
- 七位性格迥异的命中之人（白衣少女、红衣女将、银发仙子、紫衣妖姬、绿裙药师、金袍女帝、黑衣女侠）随剧情邂逅，姓名每世随机；女性玩家走独立男 NPC 池。
- 好感度 → 结为道侣 → **双修修炼加成 20%** → 添丁、家庭事件、高堂奉养（父母好感影响结局）。

### 6. 视听呈现
- **原创程序化配乐**：Web Audio API 实时合成，B 大调 90 BPM，A-A'-B 三段循环，钢片琴主旋律 + 弦乐铺底 + 笛子低八度跟奏 + 古筝五声琶音 + 木鱼，带音量滑条、页面隐藏自动压低（ducking）。
- **独立 UI 音效引擎**（与配乐开关互不影响）、金色粒子背景、标题呼吸辉光。
- **CG 场景系统**：内置手绘风 SVG 场景（初遇、提亲、添丁、双修等）；放入 `assets/cg-<场景>.png` 或 `.mp4` 即**自动热替换**为 AI 生成图/视频，支持按女主编号单独出图。
- 人物立绘：AI 生成 PNG 为主，缺图自动回退内联 SVG 剪影，男主 Canvas 烘焙变色变体。

### 7. 体验便利性
- localStorage **自动存档** + 「续前世 · 读档」；「岁月如梭」一键五载快进；键盘快捷键（空格 / 回车推进，数字键 1-9 选项）；全屏 + 横屏锁定适配移动端；重开一世一键轮回。

## 三、技术架构

**选型**：原生 HTML / CSS / JavaScript 三件套，零框架、零构建、零后端、零运行时依赖——任何一个静态文件服务器（甚至双击 index.html）即可运行。

```
仙途人生模拟器/
├── index.html          # 结构层：三块 screen（开始 / 游戏 / 结局）+ 事件卡 + banner
├── style.css           # 表现层：CSS 变量主题（金/玉/紫国风夜色）、响应式、动画
├── game.js             # 逻辑层：全部游戏逻辑（2,772 行，单文件分 16 个注释分区）
├── assets/             # AI 生成立绘（7 女主 + 男主）
├── backups/            # 迭代快照（国风改版 / 新配乐 / 打磨 / 修复 等版本）
├── preview.html        # 立绘预览工具页（开发辅助）
├── CG真人风提示词包.md  # AI 美术工作流文档（11 个 CG 场景提示词）
└── serve.ps1           # 本地静态服务器（可选）
```

`game.js` 内部分层（自上而下）：

| 分区 | 职责 |
|---|---|
| 工具 & 基础数据 | 随机数、加权抽取；TALENTS / ORIGINS / ROOTS / REALMS / SALARY / HEROINES 等纯数据表 |
| 立绘 & CG | SVG 立绘合成、PNG 探测与回退、Canvas 变体烘焙、CG 场景库与外部资源热替换 |
| 状态管理 | `newState` 构造一世状态；`applyFx` 统一数值结算并产出浮动变化标签 |
| 事件库 | `EVENTS`（随机事件，含权重与条件）+ `MILESTONES` / `CHOICE_EVENTS`（年龄驱动的抉择剧情） |
| 行为系统 | `ACTIONS` 定义 + `applyAction` 各行为收益公式（含枯竭惩罚与随机遭遇） |
| 回合引擎 | `doTurn → buildQueue → processQueue → tickYear → checkDeath → die` 的主循环；`fastForward` 五载快进 |
| 渲染层 | 侧栏状态、行为按钮、事件卡（含 CG 挂载）三处 DOM 渲染 |
| 结局 & 存档 | 结局称号 / 评分 / 藏头诗 / 生平回顾；localStorage 自动存档与读档 |
| 音频 | `Music`（Web Audio 程序化配乐）与 `Sfx`（UI 音效）两个独立 IIFE 模块 |
| 初始化 | 粒子背景、事件绑定、快捷键、浏览器自动播放策略解锁 |

**关键工程决策**：
- **数据驱动**：事件、行为、境界、女主全部是声明式数据表，新增内容即加数据不改引擎。
- **优雅降级**：立绘/CG 缺文件 → 回退内置 SVG；全屏 API / 横屏锁定不支持 → 静默忽略；Web Audio 需手势解锁 → 首次交互自动 unlock。
- **性能**：小屏自动减少背景粒子数量保帧率；日志上限 420 条防 DOM 膨胀。
- **安全**：serve.ps1 内置路径穿越防护（`StartsWith($root)` 校验）与显式 MIME 表。
- **版本管理**：以 `game.js.<特征>-<日期>.bak` 快照方式保存 5 个迭代版本，可随时回滚。

## 五、部署方式

**方式一 · 直接打开（零部署）**
双击 `index.html` 即可在浏览器离线游玩，全部功能本地运行，无需网络与服务器。

**方式二 · 本地静态服务器（推荐）**
项目自带 `serve.ps1`（基于 PowerShell 原生 HttpListener，无任何依赖）：

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
# 输出：serving ... at http://localhost:8642/
```

浏览器访问 `http://localhost:8642/` 即可。任何等效静态服务器同样可用，例如：

```bash
python -m http.server 8642   # 然后访问 http://localhost:8642/
```

**方式三 · 公网托管**
整个目录即静态站点，可直接发布到任意静态托管平台（对象存储静态网站、GitHub Pages、Vercel 等），无需后端。移动端浏览器访问自动适配（视口锁定、全屏 + 横屏模式）。
